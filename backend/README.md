# Student Management System (Spring Boot + JWT Auth)

This is a backend REST API built using **Spring Boot** with **JWT-based authentication**. It supports user registration, login, and protected endpoints for managing student records.

## 🚀 Features

- ✅ User Registration & Login (with BCrypt password hashing)
- 🔐 JWT-based Authentication
- 🧑‍🎓 Student CRUD endpoints (secured)
- 🛡️ Stateless Security using Spring Security Filters
- 💾 MySQL database integration

## 🛠️ Tech Stack

- Java 21
- Spring Boot 3.x
- Spring Security
- JWT (via `jjwt` library)
- MySQL
- Maven
